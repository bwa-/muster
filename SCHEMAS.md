# Muster JSON Schemas

This directory contains JSON schemas for muster configuration files and test validation.

## Configuration File Schemas (IDE Support)

These schemas provide autocomplete and validation for YAML configuration files:

### [`workflow-schema.json`](./workflow-schema.json)
**Purpose**: JSON Schema for Workflow YAML files  
**Use with**: `~/.config/muster/workflows/*.yaml`

Provides IDE support for:
- Workflow structure validation
- Step definitions with `tool`, `args`, `store`, `condition`
- forEach loops with `items` and `step` templates
- Template syntax: `{{.args.name}}`, `{{.results.step_id}}`, `{{.item}}`
- Argument definitions with type validation

**IDE Configuration Example (VSCode)**:
```json
{
  "yaml.schemas": {
    "/path/to/muster/workflow-schema.json": "~/.config/muster/workflows/*.yaml"
  }
}
```

### [`mcpserver-schema.json`](./mcpserver-schema.json)
**Purpose**: JSON Schema for MCPServer YAML files  
**Use with**: `~/.config/muster/mcpservers/*.yaml`

Provides IDE support for:
- MCP server configuration validation
- Command and environment variable specification
- AutoStart and toolPrefix configuration
- Type validation (currently only `localCommand`)

**IDE Configuration Example (VSCode)**:
```json
{
  "yaml.schemas": {
    "/path/to/muster/mcpserver-schema.json": "~/.config/muster/mcpservers/*.yaml"
  }
}
```

## Test Validation Schema

### [`schema.json`](./schema.json)
**Purpose**: Generated schema for muster core API tools  
**Generated by**: `muster test --generate-schema`  
**Use**: Test scenario validation

This file is automatically generated and documents all available core tools for test scenarios. Do not edit manually.

## Setting Up IDE Support

### Visual Studio Code

1. Install the YAML extension (`redhat.vscode-yaml`)
2. Add to your `.vscode/settings.json`:

```json
{
  "yaml.schemas": {
    "/home/daddadudda/repos/muster/workflow-schema.json": [
      "**/workflows/*.yaml",
      "**/workflow-*.yaml"
    ],
    "/home/daddadudda/repos/muster/mcpserver-schema.json": [
      "**/mcpservers/*.yaml",
      "**/mcpserver-*.yaml"
    ]
  }
}
```

### JetBrains IDEs (IntelliJ, PyCharm, etc.)

1. Go to **Settings** → **Languages & Frameworks** → **Schemas and DTDs** → **JSON Schema Mappings**
2. Add new mapping:
   - **Schema file**: `/path/to/muster/workflow-schema.json`
   - **Schema version**: JSON Schema version 7
   - **File path pattern**: `**/workflows/*.yaml`
3. Repeat for `mcpserver-schema.json` with pattern `**/mcpservers/*.yaml`

## Schema Features

Both schemas provide:

✅ **Autocomplete**: Property suggestions as you type  
✅ **Validation**: Real-time error detection for invalid configurations  
✅ **Documentation**: Hover over properties to see descriptions  
✅ **Required Fields**: Clear indication of mandatory vs optional fields  
✅ **Enum Values**: Dropdown lists for fields with fixed values  
✅ **Pattern Validation**: Regex validation for names, IDs, etc.

## Example Usage

With IDE support configured, you'll get:

- **Autocomplete** when typing step properties
- **Warnings** for missing required fields like `id` or `tool`
- **Enum suggestions** for `type` fields (string, integer, boolean, etc.)
- **Inline documentation** for forEach loops and template syntax
- **Validation errors** for invalid patterns or types

## Updating Schemas

- **Workflow/MCPServer schemas**: Edit manually when CRD structure changes
- **Test schema**: Regenerate with `muster test --generate-schema`
